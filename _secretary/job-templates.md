# 応募文テンプレート（クラウドワークス・ランサーズ）

軸は「GAS×生成AIでの業務自動化」と「福祉事業所向けの記録ツール（運営指導を通過）」。
LP・ホームページ制作は載せない（2026-10-01確定）。連絡先・外部URL・SNSは書かない。
応募の送信はあなた本人が押す（自動送信しない）。数字や実績は事実だけを書く。

## 1件にかける時間の目安
共通部分はそのまま貼り、【ここだけ案件ごとに書く】の2か所（①受け止め／③対応方針）に3〜5分。10件で約1時間。
慣れるまでは丁寧さを優先して、15件に増やすのは返信が来てから。

---

## 基本の型（5ブロック）

```
【① 案件の受け止め（案件ごとに書く・2〜3文）】
はじめまして。募集内容を拝見しました。「{案件の困りごとを、相手の言葉でそのまま言い直す}」とのことで、
{なぜ自分が力になれるか、1文}。

【② 自己紹介と実績（共通）】
Google Apps Script（GAS）とGeminiやClaudeなどの生成AIを使って、スプレッドシートまわりの業務自動化を行っています。
福祉事業所向けに、簡単なコメントを入力するだけでGeminiが記録を作成するツールを開発しました。
このツールで作った記録は、運営指導を通過した実績があります。

【③ 対応方針（案件ごとに書く・3〜5文）】
{どのデータを、どこから、どこへ、どう動かすか}を、GASで自動化する形で考えています。
{想定する作り・使い方}。
{つまずきそうな点があれば、先に一言}。

【④ 確認したいこと（案件ごとに1〜2個）】
・{今の作業の流れ（手作業の頻度・件数・使っているファイル）}
・{ご希望の納期と、使う方の人数}

【⑤ 稼働と締め（共通）】
平日18〜23時に稼働しています。メッセージには基本24時間以内にご返信します。
まずは今のやり方を教えていただければ、できる範囲と進め方をお伝えします。どうぞよろしくお願いいたします。
```

金額は、案件の内容を見てから書く。決まった数字を先に出さない（空欄のまま「内容を確認のうえご提案します」でよい）。

## 案件タイプ別：③の書き出し例

### A. スプレッドシートの集計・転記・帳票づくり
```
複数のシートに分かれたデータを、GASで1つに集約して、ボタン1つで集計表が出る形を考えています。
入力側のシートはいまの形のまま使えるようにして、慣れた操作を変えないようにします。
集計の条件（期間、担当者別など）は、シート上で選べる形にします。
```

### B. 生成AIで文章を作る・要約する（記録、返信文、報告書など）
```
入力フォームやシートに書いた短いメモをもとに、Gemini（またはClaude）が文章の下書きを作る仕組みを考えています。
福祉記録のツールでは、決まった書式と言い回しを守りながら、職員の方が最後に必ず確認して直せる形にしました。
AIの出力をそのまま使わず、人が確認する手順を入れる前提でご提案します。
```

### C. 外部サービスとの連携・通知（Chatwork、LINE、メール、API）
```
スプレッドシートの更新をきっかけに、{Chatwork / LINE / メール}へ自動で通知する形を考えています。
送信の履歴をシートに残して、届いたかどうかを後から確認できるようにします。
APIの利用料などが別に必要になる場合は、先にお伝えします。
```

## 応募前チェック（30秒）
- [ ] 募集文を最後まで読んだ。依頼の中心は「GASやスプレッドシートの自動化」か
- [ ] 自分で作れる範囲か（迷ったらURLを送って相談）
- [ ] 発注者の評価・本人確認・過去の発注実績を見た
- [ ] ①と③が、その案件の言葉で書けている（コピペのままではない）

## 避ける案件（見つけたらスキップ）
- 評価も発注実績もない発注者（初回で大きな金額を提示してくる）
- 「LINE・Telegram・メールに移ってください」と、サイト外のやり取りに誘導してくる
- 先に費用や登録料を求める、副業塾や教材の案内が混ざっている
- 「誰でも簡単に高収入」など、仕事内容が曖昧で報酬だけが強調されている
- 成果物の権利を、報酬に見合わない形で全部譲渡する条件
- 個人情報・口座情報を先に求める

## 好む案件（優先して応募）
- スプレッドシートの集計・転記・帳票・通知の自動化（小粒で、1〜5万円規模）
- 評価のある発注者の継続案件
- 記録・報告書の文章づくりに生成AIを使いたい、という相談

## 返信が来たら（面談）
- 質問は「今の作業の流れ」「データの量」「使う人数」「期限」の4つを軸にする
- 個人情報を含むデータは、ダミーに置き換えた状態で共有してもらう
- 見積りは、確認できた範囲だけで出す。曖昧な部分は「確認後に再見積り」と書く
