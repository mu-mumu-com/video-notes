# プロジェクト目的シート

秘書エージェント（クラウド週次チェック・ローカル呼び出し共通）が読む、各プロジェクトの目的と現状のレジストリ。目的が変わったり新しいプロジェクトが増えたら、ここを更新する。

## 運用ルール
- 週次チェックは「対象プロジェクト」のみを見る
- 「除外プロジェクト」は対象外（本人が個人用・保留と判断済み）
- 目的や状態が古くなっていそうな場合は、秘書がユーザーに確認を促す

## 対象プロジェクト

### adult-directory
- repo: https://github.com/mu-mumu-com/adult-directory
- 目的: アフィリエイトリンク集サイトによる収益化
- 状態: 公開済み・運用中
- チェック観点: 直近のコミット状況、収益導線（バナー/リンク）が壊れていないか、長期間放置されていないか

### okinawa-navi（てだこナビ）
- repo: https://github.com/mu-mumu-com/okinawa-navi
- 目的: 沖縄の行政支援制度を「困りごと」から探せる案内サイト。情弱・障害者向けアクセシビリティ最優先。実際に困っている人に使われ、支援窓口に繋がること
- 状態: 公開済み
- チェック観点: 制度情報の更新漏れ、アクセシビリティ基準（コントラスト・文字サイズ等）の劣化がないか

### momemo
- repo: https://github.com/mu-mumu-com/momemo
- 目的: ココナラでの受注＋Instagram集客の導線となるポートフォリオサイト。Instagramプロフィールに貼る前提
- 状態: サービス開始前の準備段階
- チェック観点: 公開に足る完成度か、何が足りないか、ig-auto-replyとの導線が繋がる想定になっているか

### サンプルサイト（shiro-clinic / kuruma-ya）
- repo: https://github.com/mu-mumu-com/K-sannpuru（mainブランチ=shiro-clinic、worktree-kuruma-ya-3d-portfolioブランチ=kuruma-ya）
- 目的: ココナラ営業用の差別化サンプル・ポートフォリオ。特にkuruma-yaは3Dスクロール演出の実力を示すデモ
- 状態: 継続開発中
- チェック観点: 進捗が止まっていないか、ココナラ出品時にすぐ提示できる完成度か

### bento-order
- repo: https://github.com/mu-mumu-com/bento-order
- 目的: 職場近くの弁当屋が自作サイトを作っていたのを見て試作。サブスク化を検討したが競合サービスが多く保留中。現状はココナラ用の実装サンプルとして保持
- 状態: 開発ひと段落・サブスク展開は保留
- チェック観点: サブスク化を再検討する動きが出ていないか、単体サンプルとして提示できる状態を保っているか

### bizplan-app
- repo: https://github.com/mu-mumu-com/bizplan-app
- 目的: 銀行融資向け事業計画書をAIで作成する専用ツール。単体プロダクトとして販売できるか検証中
- 状態: 実装済み・販売検証前
- チェック観点: 販売に向けて何が足りないか（LP、価格設定、決済導線など）

### ig-auto-reply
- repo: https://github.com/mu-mumu-com/ig-auto-reply
- 目的: Instagramコメントへの自動返信によるmomemo/ココナラ導線への集客効率化
- 状態: 実装済み
- 注意: Meta規約上、ユーザーが先にアクションした後24時間以内のリアクティブ返信のみ許可。一方的な営業DM自動送信は規約違反になるため、その方向への拡張は提案しない
- チェック観点: 規約範囲内の運用を保っているか、返信内容の質
