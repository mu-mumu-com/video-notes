# 検討済みアイデア台帳

りかちゃんがこれまでに検討・提示した事業アイデアと、実現可能性調査の結果、ユーザーの反応を記録する。重複提案を防ぎ、後から「あのアイデアどうだったっけ」を参照するための台帳。

## 記載フォーマット
```markdown
### <アイデア名>（<提示日 YYYY-MM-DD>）
- 概要: ...
- 実現可能性調査結果: 必要ツール / 概算費用 / 難易度
- ユーザーの反応: やる / やらない / 保留
- 備考: ...
```

### ig-auto-replyのサブスク型ミニSaaS化（2026-08-20）
- 概要: 個人開発の成功事例（Instagram用チャットボット「iDM」、月額約4,000円×約70ユーザーで月30万円弱のMRR）を見て、既存の`ig-auto-reply`（自分専用で稼働中のInstagramコメント自動返信ツール）を同様に他ユーザー向けサブスクとして外部提供できないか調べた
- 実現可能性調査結果:
  - 必要ツール: Stripe Billing(課金)、Clerk or Supabase Auth(顧客ごとの認証)、Meta App Review + Business Verification(法人確認書類提出が必要)
  - 概算費用: 顧客数十人規模で月数千〜1万円台のインフラ費+Stripe手数料(約4.3%)から開始可能
  - 難易度: コード自体はAIエージェントで書けるが、**最大の壁はコードではなくMeta App Reviewの審査**（スクリーンショット・使用例動画の提出、数日〜数週間、差し戻しあり）とBusiness Verification
  - 規約: 「コメント等への先行アクションから24時間以内の返信」の枠内であれば規約上SaaS化は可能。ただしコメントへの自動返信は750件/時間、自動DMは200件/時間/アカウントの上限あり(2024年10月にMetaが引き下げ済み)
  - 代替: ManyChat($14〜139/月)・Chatfuel($23.99〜)等の既存ノーコードSaaSで同等機能は代替可能。自作の意義は「日本語UI/業種特化」「粗利率(手数料を払わず直接課金)」
- ユーザーの反応: (未回答)
- 備考: 情報源は調査ログ参照。次に動くなら、Meta App Review申請の要件（審査に必要な動画・書類）から具体的に洗い出すのが現実的な次の一歩

### Threads投稿管理スプレッドシート＋自動投稿＋AI分析（2026-09-14）
- 概要: Threads(自分の持論・仮説投稿アカウント)の運用を効率化するため、①過去投稿+反応数(いいね等)を記録するスプレッドシート、②スプレッドシートに書いた内容を指定時刻に自動投稿する予約機能、③反応データをAIが分析して「どんな投稿が伸びるか」を教える機能、の3点セットを作りたいという要望
- 実現可能性調査結果:
  - 必要ツール: Threads API(Meta公式、無料)、Google Sheets API(無料)、スケジュール実行(Cloudflare Workers Cron TriggersかGAS時間主導型トリガー、どちらも無料枠内)、AI分析(Claude/Gemini API、従量課金)
  - 概算費用: 実質ほぼ0円〜数百円/月(AI分析の呼び出し頻度次第)
  - 難易度: バイブコーディングで十分実現可能。過去に構築したCloudflare Worker系自動化(rika-line-bot等)と同程度〜やや易しい。**最大の注意点はThreads長期アクセストークンが60日で失効すること**——自動リフレッシュの仕組みを最初から仕込まないと、ある日突然投稿が止まる
  - 審査: 自分のThreadsアカウントのみで使うなら**Meta App Reviewは不要**(他人のアカウントを連携させる外部向けサービスにする場合のみ必要)
  - 代替: Metricool(無料枠あり)・Publer(無料〜$5/月)が既にThreads対応の予約投稿+基本分析を提供。「予約投稿」「反応数の確認」だけならこちらを使う方が自作より圧倒的に速い
- ユーザーの反応: (未回答・提示直後)
- 備考: **りかちゃんの推奨は折衷案** — 予約投稿自体はPubler/Metricoolの無料枠に任せ、そこ(またはThreads APIのインサイト)からデータをスプレッドシートに集約し、「AIによる反応分析」の部分だけを自作する構成。要望の核心(自分の書式で一元管理・日本語でAIに分析させる)は自作でしか満たせないが、投稿予約という実装コストが一番高い部分は既存サービスで代替できるため。フル自作(Threads API直叩き)を選ぶ場合はトークン自動更新の実装を最初のタスクに入れること
