# マーケットイン思考とSNS運用に必要な能力

## ひとことで
「誰が/何に困り/いくら払うか/すでに何を試したか」でニーズを判断するマーケットイン思考と、SNS運用に必要な6つの能力、SNS運用が自社の弱点まで可視化してしまうという指摘をまとめた画像投稿（SNS運用コンサル系アカウントの企画設計解説）。

## 手順 / やり方
マーケットインの出発点として次を確認する:
1. 誰が困っているのか
2. 何に困っているのか
3. いくらなら払うのか
4. すでに何を試しているのか
→ 需要は「欲しい」ではなく「お金を払う」で判断する。口では評価されても購入・依頼につながらなければ市場では需要にならない

SNS運用に必要な能力（単なる投稿作業以上に必要):
- 顧客心理を読む / 企画をつくる / 情報を翻訳する
- 撮影・編集する / 継続的に改善する / 企業の価値を外部視点で捉える

SNS運用で浮き彫りになりやすい企業の課題:
- 自社の魅力の枯渇 / 顧客に伝わっていない / 社内の認識がバラバラ / 商品の強みを言語化できていない
→ SNSは企業自身が見たくない部分も可視化する

## 要点メモ
- 企業には商品・サービスの専門家はいても、それを顧客に伝わる形へ変換する人がいるとは限らない

## 信憑性・再現性
- 信憑性: 高い — マーケティングの基本論として妥当（顧客開発・リーンスタートアップ的な問いと一致する）
- 再現性: 高い — 自分の商品企画やヒアリング項目にそのまま使えるチェックリスト

## 思考パーツ・自分ごと化
- 保存メリット: 高い — ホームページ制作の提案・ヒアリング項目にそのまま転用できる
- 取り入れた方がいい部分: 新規案件のヒアリング時に「誰が/何に困り/いくら払うか/すでに何を試したか」を確認項目に加える
