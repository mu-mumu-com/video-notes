# タイピングカーソル風テキスト演出をFilmoraで再現

## ひとことで
タイプライターのようにカーソルが動きながら文字が出てくるテキスト演出を作る手順。元動画はCapCut手順だが、Filmoraには同名プリセット(「ドットカーソル」)が無いため、Filmoraのマスク＋キーフレーム機能で同等の見た目を再現する代替手順に置き換えて保存する。

## 手順 / やり方(元のCapCut版)
1. 元の風景映像とは別に、黒い画像を1枚用意する。
2. CapCutで黒画像をアップロードし、太めのフォントでテキストを入力する。
3. アニメーションから「ドットカーソル」を検索して選択し、左上のドットカーソルを選んで秒数を2.5秒に設定する。
4. アニメーション終了直後にキーフレームを打ち、2秒ほど右へ動かしながら文字を拡大し、白い部分でマスクする。
5. これを保存し、新しい動画で風景映像をアップロードする。
6. オーバーレイで先ほどのテキスト動画を重ね、画面位置を合わせる。
7. 「スプリット」で分割し合成すれば完成。

## 手順 / やり方(Filmora代替版・未検証の想定手順)
CapCutの「ドットカーソル」プリセットに相当する機能がFilmoraには無いため、マスク機能とキーフレームを組み合わせて再現する想定手順(実際にFilmoraで試して確認するまでは仮の手順として扱う)。
1. 新規トラックに黒背景のカラークリップ(または黒画像)を配置する。
2. その上にテキストクリップを追加し、太めのフォントを選ぶ。
3. テキストの上に矩形マスクを重ね、マスクの位置・幅をキーフレームで左→右に動かすことで、文字が徐々に見えていく「タイピング風」の動きを作る。
4. カーソルに見立てた縦棒の図形素材を追加し、マスクの先端と同じ速度で右へ移動するようキーフレームを設定する。
5. できあがったテキスト演出を、Filmoraの「オーバーレイ(PinP)」機能で元の風景映像の上に重ねる。
6. マスク機能でテキスト部分だけを合成し、映像内の位置に合わせて配置する。
7. 必要に応じてトランジションで前後のカットとつなげる。

## 要点メモ
- FilmoraにもCapCutと同様に「キーフレーム」「マスク」「オーバーレイ(PinP)」の各機能があり、組み合わせれば同等の演出は再現可能(WebSearchで確認済み)。
- ただし完全に同じ見た目の「ドットカーソル」プリセットは存在しないため、手作業でのキーフレーム設定が必要になる。

## 信憑性・再現性
- 信憑性: 高い(元のCapCut手順について) — 特定アプリの具体的な操作手順で、誇張や不自然な主張はない。
- 再現性: 普通 — 元のCapCut手順は具体的だがUIバージョン差で項目名が変わる可能性がある。Filmora代替版は機能の存在は確認済みだが、実際にFilmora上で試して手順を確定させる必要がある(未検証)。

## 思考パーツ・自分ごと化
- 保存メリット: 薄い(操作Tips寄りで、思考の型としての汎用性は低い)。
- 取り入れた方がいい部分: ココナラやmomemoのSNS運用支援でリール制作を頼まれた時、テキスト演出のリファレンスとして使える。Filmora版は一度実際に試して手順を確定させてから使う。
