# ClaudeとAmazonアソシエイトでSNS投稿を自動化する方法

## ひとことで
Claude Desktopアプリを使い、Amazonアソシエイト（アフィリエイト）のリンク生成からSNS投稿文の作成・予約投稿までを一連で自動化する方法。

## 手順 / やり方
1. 「Amazonアソシエイト」で検索し、公式サイトから登録する（既にAmazonアカウントがあればそのまま簡単に登録できる。発信しているSNSアカウントも合わせて登録し、審査を申請する）。
2. 紹介したい商品のページを開き、画面上の「リンクを生成」ボタンをクリックしてSNS投稿用のアフィリエイトリンクを作成する。
3. Claude Desktopアプリを開き、「このリンクの商品を30代の会社員向けに、PREP法を使って複数パターン・ツリー投稿で作って、一行目で手が止まる文にして」のように具体的な条件を指定して投稿文を生成させる。
4. できた文章をTypefully（予約投稿ツール）で1時間ずつずらして予約投稿する。
5. これを繰り返し、Claudeに投稿内容を改善させていく。

## 要点メモ
- Amazonアソシエイトの審査（発信SNSアカウントの登録込み）に通る必要がある点が前提条件。
- プロンプトでは文章の「型」（PREP法・ツリー投稿・一行目で手が止まる文）を具体的に指定している。

## 信憑性・再現性
- 信憑性: 高い — 登場するサービス・手法（Amazonアソシエイト、Claude Desktop、Typefully、PREP法）はいずれも実在し、内容に矛盾や誇張的な収益主張もない。
- 再現性: 高い — 必要なもの・手順が具体的に示されており欠落がない。Amazonアソシエイトの審査通過のみ前提条件として留意する。

## 思考パーツ・自分ごと化
- 保存メリット: 「アフィリエイトリンク生成→AIに文章生成を丸投げ→予約投稿ツールで時間差公開」という分業フローは、商品紹介に限らず情報発信全般に応用できる型。
- 取り入れた方がいい部分: AIへのプロンプトで「PREP法・ツリー投稿・一行目で手が止まる文」のように文章の型と条件を具体的に指定するやり方は、提案文やSNS発信でもそのまま流用できる。
