# Claudeに素材を見せて動きまで指定するサイト制作

## ひとことで
お菓子のパッケージや名刺の画像をClaudeに見せ、「操作したらどう変わるか」まで指示して、素材らしさのあるサイトを作る方法。同じ投稿者(m.ndgn_y)の2本をまとめた。

## 手順 / やり方
1. 素材の画像を用意する（例: カラムーチョの袋、たい焼き店の名刺）
2. 店名・営業時間・住所などの情報を渡す（架空でよい）
3. 素材の色・書体・雰囲気を引き継ぐように伝える
4. 操作したらどう変わるかを具体的に指定する
   - 辛さレベルを上げると、炎が大きくなり背景色も変わる
   - たい焼きが泳いで登場 → スクロールで割れる → あんこが飛び出す → 中身を選ぶと味と色が変わる
5. 注文完了まで試せるデモ画面も作らせる

### 再構成したプロンプト（推定。元のプロンプトではなく、未検証）
元の全文は投稿の固定コメントにあり、ログインが必要で取得できなかった。キャプションの説明から組み立てたもの。
```

  例: スクロール→魚が割れる→あんこが飛び出す／中身を選ぶ→味と色が変わる
- 注文完了まで試せるデモ画面もつける
※実在の店舗ではなく架空の制作物
```

## 要点メモ
- 色や形だけでなく「選ぶ楽しさ」まで考えると、ブランドの世界観を操作でも表現できる
- なぜレベルが高く見えるか
  - 素材（袋・名刺）にデザインがすでに入っていて、AIが迷わず「平均的なテンプレ顔」にならない
  - 素材の特徴を動きに変換しているので、デザインに理由がある
  - 成功した例だけが投稿されている可能性が高い（推測）
- 使用モデルはClaude Opus 5.5と表記されている
- 映像は画面の文字とキャプションから確認した（音声は音楽のみ）

## 信憑性・再現性
- 信憑性: 高い — 画面で完成物の動きを確認できた
- 再現性: 普通 — コツは再現できるが、元プロンプト全文は未取得。上の再構成は未検証

## 思考パーツ・自分ごと化
- 保存メリット: 「入力の質（強い参考素材）と動きの指定が差になる」という視点。Webの案件全般に使える
- 取り入れた方がいい部分: クライアントのロゴ・名刺・商品写真・パッケージを最初にAIへ渡す。デザイン指示に「操作したらどう変わるか」を1つ入れる
