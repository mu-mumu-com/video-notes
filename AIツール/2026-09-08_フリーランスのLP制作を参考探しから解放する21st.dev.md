# フリーランスのLP制作を「参考探し」から解放する 21st.dev

## ひとことで
LP/サイト制作の「デザイン参考探しで数時間溶ける」問題を、UIパーツ集 21st.dev の「気に入ったパーツのプロンプトをコピー → AI（Claude Code / Cursor 等）に貼る」だけで数分に短縮する話。

## 手順 / やり方
1. 21st.dev にアクセスし、世界中のデザインエンジニアが公開している React + Tailwind のUIパーツ（ヒーロー、ボタン、料金表、CTA など）を探す
2. 気に入ったパーツで「Copy prompt」を押す（コードではなく、AI向けの実装プロンプトがコピーされる）
3. そのプロンプトを Claude Code / Cursor / v0 / Lovable などに貼る
4. AIが自分のコードベース・スタックに合わせてそのパーツを実装する
5. コードが読めなくても、外注しなくても、プロが作った見た目のパーツが自分のLPに入る

## 要点メモ
- 動画の主張する「ヒーロー1,200種・ボタン2,000種」は個別には未検証。公式は「12,000点以上のUIパーツ」と表記。ざっくり「大量にある」は事実。
- 従来の参考サイトは「コードを読める人向け」。21st.dev はプロンプトコピーなので、実装をAIに丸投げできる。
- 動画の最後は「コメントでデザインと送ればURLを送る」というエンゲージ稼ぎ構成。情報自体は正しいが煽りは割り引く。
- 自分の使いどころ: momemo / ココナラ案件のLPで、ヒーロー・料金表・CTA など「毎回ゼロから悩む定番パーツ」を作る前に一度 21st.dev を見て Copy prompt を試す。

## 料金（2026-09 時点・要検証で確認済み）
- **無料**: マーケットプレイスの閲覧・プレビュー・検索は無制限。ただし「Copy prompt → AIで実装」は**1日2コンポーネントまで（月100クレジット）**。
- **Builder（AIなし）**: 月$6〜8。ブラウズ・プレビューのみ。
- **Builder + AI**: 月$15〜20〜。月500〜2,000クレジット。
- 毎日ガンガン使うなら実質有料。たまに1〜2パーツなら無料で足りる。
- ソース: help.21st.dev/magic-chat/pricing, 21st.dev/blog/introducing-21st-membership

## 信憑性・再現性
- 信憑性: 普通 — 21st.dev は実在。Copy prompt 機能・対応AIツール（Cursor/Claude Code/v0/Lovable）は公式説明と一致。ただし「ヒーロー1,200種」等の個別数値と「参考探しが5分」は本人の体感で裏取り不可。無料枠の1日2回制限は動画で触れていない。
- 再現性: 高い — サイトは無料で試せ、ユーザーはすでに Claude Code / バイブコーディングで開発しており前提条件を満たす。特別な審査・スキル不要。

## 思考パーツ・自分ごと化
- 保存メリット: 薄い。「AIにコード片ではなくキュレーションされたプロンプトを渡す」という発想は既にやっていることの延長。ツールの存在を忘れないためのメモという位置づけ。
- 取り入れた方がいい部分: 次のLP案件で、定番パーツ（ヒーロー/料金表/CTA）に着手する前に 21st.dev を1回見て Copy prompt を無料枠内で試す、というステップをワークフローに足す。
