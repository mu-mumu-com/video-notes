# 今週GitHubで急伸したAI開発ツールTOP5

## ひとことで
GitHubで直近1週間にスターを急激に伸ばした新興AI開発ツール5つを紹介するランキング動画。

## 要点メモ（紹介ツール、5位→1位）
1. **Book2Skill**（5位） — 技術書やPDFをAIエージェント用の学習データに変換し、Claude CodeやCopilotにスキルとして直接読み込ませるPythonツール。開発時のドキュメント参照が不要になる
2. **iHub Addon**（4位） — Claude Code等のAIエージェントに、説明抜きで実行可能な手順だけを返させるアドオン。無駄な説明を省いて即実行できる手順のみを提示
3. **BitChat**（3位） — Swift製の分散型チャットアプリ。オフライン時はBluetoothメッシュ、オンライン時はNostrプロトコルを自動で切り替える独自の分散アーキテクチャ
4. **OmniRoute**（2位） — 290以上のプロバイダー・500以上のAIモデルを単一エンドポイントに集約するOSSゲートウェイ。独自の圧縮技術でコスト消費を最大95%節約
5. **人間×AIエージェント協調プラットフォーム**（1位、Rust製） — Nostrプロトコルベースで、共通ワークスペース上でコードレビューやタスクを人間とAIが同時実行できる

## 信憑性・再現性
- 信憑性: 高い — BitChat・OmniRouteは実在し、動画の説明（Bluetoothメッシュ/Nostr切替、290+プロバイダー・500+モデル、コスト最大95%節約）とほぼ一致することを確認済み。Book2Skillのみ検索で確認できず（新しすぎる/マイナーな可能性）。スター数は動画時点のスナップショットで厳密な裏取りは不可だが、桁感は他の実測値と整合的
- 再現性: 高い — いずれもOSSで無料導入可能。ただし動画内では入手先が「メンバーランのリンク」参照とされており、この動画単体では入手経路が完結しない
