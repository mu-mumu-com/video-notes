# Claude 7つの神スキル

## ひとことで
Claude Code に入れると「Claude の中にクリエイティブチームが丸ごとできる」7つのスキルの紹介。

## 手順 / やり方
1. **動画自動生成系（Remotion系）** — 作りたいものを伝えるだけでクオリティの高いリール動画が完成
2. **superpowers** — いきなり作業せず、先に計画→サブエージェントに作業を振る→別AIがダブルチェック→改善ループまで回す。成果物の品質が底上げされる
3. **playwright** — ブラウザ操作を丸投げ。「これ調べておいて」でChromeを自動で開いて情報収集
4. **claude-code セットアップ案内** — 使い方に迷ったらこれに聞く。設定方法から次にやるべきことまで提案
5. **frontend-design** — デザインを整える。普通に作らせると出るAIっぽい見た目を消す
6. **discord** — スマホから指示が出せる。移動中でも自宅PCが動いて完成品が返ってくる
7. **skill-creator** — スキルを作ってくれる。毎日やる作業を1回覚えさせれば、次から一言で自動実行

## 要点メモ
- 「10万以上のスキルがある」は誇張。挙がっている7つはClaude Codeに実在する
- Homupe環境にはすでに superpowers / playwright / frontend-design / discord / skill-creator 等が導入済み
- 動画では導入手順を「コメントした人にDMでリンク共有」と出し惜しみしている

## 信憑性・再現性
- 信憑性: 高い — 7つとも実在のスキル。誇張は「10万以上」の部分のみ
- 再現性: 普通 — Claude Codeが前提。一部は初期設定が必要。動画自体は導入手順を明示していない

## 思考パーツ・自分ごと化
- 保存メリット: 薄い（具体的なツールの列挙）
- 取り入れた方がいい部分: この環境に未確認の「動画自動生成スキル」と「discordスキル」の稼働確認をする
