# 【第五回】さかいふうたさん研修

## ひとことで
新入社員・異動者・昇格者が入社後や役割変更後に感じる「リアリティショック」を4パターンに分類し、個人の対処法と、上司側が組織としてやるべきケアの両方を整理する回。

## 手順 / やり方

### リアリティショックの4パターンと対処
1. **モニターストレス**（周囲から評価されてる気がして辛い）
   - 対処：脱・独心バイアス（相手の反応を「1を10に」勝手に膨らませない）
   - フィードバックは「引き算」と心得る。全員が3つずつ指摘すると受け手は9個・12個になるので、伝える側が意図的に絞る
   - 速線力（能力があることと発揮されることには時間差がある）を理解する
   - チャットツールのコミュニケーションガイドラインを作る（スタンプを押す、必ずレスポンスする等）
   - ネガティブゴシッピング（陰口）は厳禁
2. **ロールモデルストレス**（優秀な人と比べて自分はダメだと感じる）
   - 対処：逆代理体験（「私は特別だから」的な発言）を避け、代理体験（「自分もできないことがある」と伝える）を起こす
   - 相手を神格化しない。誰でも「相手にあって自分にないもの」があるだけと捉える
   - 師匠を1人に絞らず複数持つ（分野ごとに頼る相手を変える）
   - 「心の師匠」は距離を置いた憧れの対象として持つ（近すぎると潰れる）
   - 良い嫉妬（この人から何を学べるか考える）と悪い嫉妬・仮想的有能感（相手を下げて自尊心を保つ）を区別する
3. **無能感ストレス**（貢献できていない気がして辛い、責任感が強い人ほど陥りやすい）
   - 対処：「無能」と「未熟」を分けて考える（今は未熟な時期なだけ）
   - 心のタイムトラベル（10年後にまだ悩んでいるか考える）
   - 遂行目標アプローチ（すごいと思われたい・失敗を恐れる）から学習目標アプローチ（できなくて当然、学べばいい）に切り替える
   - 完璧主義的懸念（完璧でないと価値がないと思い込む）ではなく完璧的努力（完璧は到達点でなく接近し続けるもの）で捉える
4. **下っぱストレス**（地味な仕事ばかりでショックを受ける）
   - 対処：固有感（なぜ自分に頼んでいるか＝強みを伝える）、貢献感（誰が喜んでいるか具体的に伝える）、将来感（この仕事が何につながるか伝える）の3つを意図的に言葉にする

### メンタルダウンの別4パターン
1. **インポスター症候群**（褒められても自分を偽物だと感じる）
   - 心のフィルター（自分の中の口癖・思い込み）がどこから来たか俯瞰する
   - 完全否定せず「モチベーションになる面」と「潰れる面」の両方を認め、うまく付き合う（with インポスター症候群）
2. **過剰適応**（空気を読みすぎて本音を言えない）
   - 心理的居場所（ここにいても大丈夫、他にも居場所があるという感覚）を作ると起きにくい
   - 本来感（自分の色でやればいい、全員に好かれるのは無理）を伝える
3. **非信頼感**（信頼されている実感がない）
   - 「言わなくてもわかるだろう」ではなく、信頼していることを言葉にして伝える
4. **インシビリティ**（無自覚な軽視・失礼な態度、ハラスメント未満）
   - 概念の共有だけでなく「こういう行動はやめよう」と具体的な行動レベルでルール化する
   - ゼロトレランスポリシー（役職に関係なく例外なく注意する）で対応する
   - 役職が高い人ほど無自覚にやりがちなので、自分にも同じルールを適用する

## 要点メモ
- リアリティショックは新人だけでなく、抜擢された新任マネージャーにも起きる。新任マネージャーはほぼ全員辛い時期を通る
- 新任マネージャーへのケア：ポジティブゴシッピング（本人のいないところで良い話をして、それが本人に伝わるようにする）で求心力を補強する
- 引き継ぎは「100点満点で70点しか渡せない」ではなく「500点満点の課題のうち450点渡せればいい」という総合得点の発想にすると気が楽になる
- ベテランほど自分のやっていることを言語化しづらくなる（暗黙知化）。難しい仕事の引き継ぎは、引き継ぐ側ではなく引き継がれる側に言語化させる方がうまくいく
- 褒める時は表面的な言葉より、具体的なエピソードを5分以上語る方が本人に響く
- 一緒に働いていない相手を褒める場合は、事前にその人のリーダーから強みやエピソードを聞いておくとよい
- 持続可能なキャリア論（第4世代）：貢献・幸福・健康の3つを同時に満たすのが良い。市場価値や転職価値ばかり追う人（第3世代的発想）は伸び悩みやすく、純粋にお客さんの喜びを軸にする人の方が結果的に評価も上がりやすい
